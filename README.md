## About

I'm an engineer in Virtual Environments and Digital Business who builds full-stack web applications and AI-assisted developer tooling. I've shipped production platforms used daily by medical staff and local government, and I maintain funky-ai, my CLI framework for AI-driven development.

## What I do

- **Full-stack web development** — Next.js, TypeScript, Node.js, and PostgreSQL for production platforms: a clinical management system for scheduling, billing, and analytics; a municipal platform that digitized social-assistance requests.
- **AI integration & agent workflows** — LLM APIs, MCP, and agent orchestration to turn AI into a practical engineering tool, not just a chat box.
- **Developer tooling** — I design CLI tools and spec-driven workflows that make AI-assisted development deterministic and reviewable.
